# Foul Play Extension

Intended to be a Chrome Extension port of [the Foul Play showdown bot](https://github.com/pmariglia/foul-play).

## Usage

Not currently released on the Chrome Web Store. Requires opening unpacked extension in Chrome using developer mode.

Release on Chrome Web Store tbd.

### Building

```
git clone https://github.com/pulkitahuja0/fp-extension
cd fp-extension
cd rs-wasm
./build.sh
```

Open `fp-extension/extension` as an unpacked extension in Chrome.
